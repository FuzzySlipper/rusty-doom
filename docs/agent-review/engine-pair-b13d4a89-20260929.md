# Engine pair b13d4a897b41 review

Engine task rusty-engine #8861; it also closes rusty-doom #8845. Doom moves
from pair `f1d747afc01c` to `b13d4a897b41`, past the #8840 borrowed-result
change.

## Migration

- **Trigger facts.** Movement reconcile iterates `SpatialTriggerFact` from
  `Facts.Span`. That covers the canonical pickups and world triggers, and the
  recipe gameplay (which previously called `ReadTriggerFactAt` per index). The
  `Present` checks went away with the indexed reads.
- **Trigger lifecycle.** `SetTriggerActive` returns `SpatialTriggerLifecycleResult`.
  `CanonicalPickupTriggerStateFact` keeps `Active`, the overlap count and the
  cause. Its `RevisionBefore`/`RevisionAfter` are gone, because the Engine no
  longer has trigger revisions.
- **Hazards.** `ReconcileHazardOverlaps` reads `ReadTrigger(...).Subjects` once
  and asks whether the player is among them. The per-overlap
  `ReadTriggerOverlapAt` loop and its `Present`/`Trigger`/`Revision` recheck
  are gone (#8845 item 3).
- **Renames.** `NavigationStepReceipt` → `NavigationStepResult`, with
  `PathLen` → `Path.Length`. `AnimationRealizationReadout` →
  `AnimationRealizationResult`, with `RetainedFactCount` → `Facts.Length`.
  `PresentationFactsReadout` → `PresentationFactsResult`.

## #8845 removals

1. **`TriggerRevision` mirror.**
   - Removed from `LoadingBayPickupStateComponent`, `LoadingBayPickupSnapshot`,
     `PickupLifecycleFact` and the HUD rows.
   - The rejected-pickup branch no longer calls `ReadTrigger` just to copy a
     revision.
   - Old saves still load: the save codec uses default `System.Text.Json`
     options, which skip unmapped members, so a saved `TriggerRevision` is
     ignored.
2. **`MaximumPickupBindings`.** Removed from the tuning record, along with its
   constructor equality check and its HUD row. The generated catalog is the
   only count.
3. **Hazard readback recheck.** See Hazards above.
